无桨固定台架：真实传感器链路侧吸与 OFFBOARD 电机测试命令
================================================================

适用范围
--------
- 全部桨叶已拆除，机体可靠固定。
- 使用真实前向 L1、真实顶向 L1、真实 MAVROS/PX4、真实电调和电机。
- 侧吸请求由终端发送，不使用遥控器通道触发。
- ALTCTL 下先由操作员给电机初始转速，随后无扰切换到 OFFBOARD。
- 接管起始推力允许 MAVROS 完整归一化范围 0.0～1.0。
- 接管第一帧保持 ALTCTL 当前目标推力，随后 1.0 秒平滑过渡到 0.45。
- 平滑结束后，正式侧吸输出上限为 0.45。

重要说明
--------
1. 不要同时运行 lidar_dual.launch 和 wall_motor_bench.launch。
2. MAVROS 和雷达节点都需要 dialout 串口权限。
3. 以下启动命令使用 sg dialout -c，避免旧登录会话没有刷新 dialout 组。
4. PX4 进入 OFFBOARD 前，/mavros/setpoint_raw/attitude 必须已经持续发布。
5. 顶向和前向传感器都必须有效，状态机才会启动。

终端 1：连接 MAVROS
-------------------

sg dialout -c "bash -lc 'cd /home/art/桌面/catkin_ws && source devel/setup.bash && exec roslaunch mavros px4.launch fcu_url:=/dev/serial/by-id/usb-Auterion_PX4_FMU_v6X.x_0-if00:57600'"

预期看到：

CON: Got HEARTBEAT, connected.
FCU: PX4 Autopilot


终端 2：启动完整真实侧吸链路
----------------------------

sg dialout -c "bash -lc 'cd /home/art/桌面/catkin_ws && source devel/setup.bash && exec roslaunch px4_wall_ceiling_control wall_motor_bench.launch output_enabled:=true flight_mode_enabled:=true hover_thrust:=0.45 max_thrust:=0.45 thrust_handover_ramp_s:=1.0 require_min_altitude:=false estimator_timeout_s:=1.5 state_timeout_s:=1.5'"


终端 3：检查完整节点
--------------------

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rosnode list | rg 'mavros|ceiling_lidar|front_lidar|sensor_range_manager|terminal_operator|flight_mode_manager|wall_perch_decision|attachment_output_mux'

必须包含：

/mavros
/ceiling_lidar_node
/front_lidar_node
/sensor_range_manager_node
/terminal_operator_node
/flight_mode_manager_node
/wall_perch_decision_node
/attachment_output_mux_node

本流程不应出现：

/operator_gate_node


终端 3：检查飞控连接
--------------------

rostopic echo -n 1 /mavros/state

启动阶段至少应满足：

connected: True
mode: "ALTCTL"


终端 3：检查真实传感器
----------------------

rostopic echo -n 1 /sensor/health

必须同时满足：

ceiling_valid: True
front_valid: True

检查两路距离：

rostopic echo -n 1 /sensor/front/range
rostopic echo -n 1 /sensor/ceiling/range

距离不能是 nan。

检查更新频率：

rostopic hz /sensor/front/range

按 Ctrl+C 结束后继续：

rostopic hz /sensor/ceiling/range

按 Ctrl+C 结束。


终端 4：侧吸状态监控
--------------------

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rosrun px4_wall_ceiling_control wall_perch_state_monitor.py   _status_topic:=/wall_perch/status   _health_topic:=/sensor/health   _state_topic:=/mavros/state   _odom_topic:=/mavros/local_position/odom   _bell:=true

预期初始状态：

启动监控 -> IDLE

状态变化时，该终端会显示前向距离、顶向距离、原因和故障次数。


步骤 1：在 ALTCTL 下建立初始电机转速
-----------------------------------

通过飞控正常操作：

1. 切换到 ALTCTL。
2. 解锁。
3. 缓慢增加油门，使无桨电机达到需要的初始转速。
4. 保持固定机体姿态稳定。

检查：

rostopic echo -n 1 /mavros/state

必须达到：

connected: True
armed: True
mode: "ALTCTL"

查看 PX4 当前归一化目标推力：

rostopic echo -n 1 /mavros/setpoint_raw/target_attitude | rg 'type_mask|thrust'

接管起始推力允许 0.0～1.0。type_mask 不应忽略 thrust。


步骤 2：发送正式侧吸请求
------------------------

另开终端：

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rostopic pub -1 /attachment/terminal_command std_msgs/String "data: 'wall'"

确认终端操作节点接受指令：

rostopic echo -n 1 /operator/command

必须显示：

mode: 3
enable_control: True
source: "terminal"


终端 5：观察 OFFBOARD 切换阶段
-------------------------------

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rostopic echo /attachment/flight_phase

另开一个终端查看阶段失败原因：

cd /home/art/桌面/catkin_ws
source devel/setup.bash
rostopic echo /attachment/flight_phase_reason

预期顺序：

PRESTREAM
ENTERING
ACTIVE


终端 6：确认 OFFBOARD 设定值预发送
----------------------------------

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rostopic hz /mavros/setpoint_raw/attitude

预期约为：

average rate: 50 Hz

确认持续发布后按 Ctrl+C。


步骤 3：进入 OFFBOARD
---------------------

正常情况下，flight_mode_manager_node 会在预发送持续至少 1.5 秒后自动请求 OFFBOARD。

只有在已经看到：

1. /attachment/flight_phase 为 ENTERING；
2. /mavros/setpoint_raw/attitude 约为 50 Hz；

但飞控仍未进入 OFFBOARD 时，才显式执行：

rosservice call /mavros/set_mode "{base_mode: 0, custom_mode: 'OFFBOARD'}"

预期返回：

mode_sent: True

确认：

rostopic echo -n 1 /mavros/state

必须显示：

armed: True
mode: "OFFBOARD"

不要在设定值频率为零或仍未建立 PRESTREAM 时强制切 OFFBOARD。


步骤 4：确认侧吸取得输出权
--------------------------

rostopic echo -n 1 /attachment/output_owner

侧吸取得输出权时：

data: 2

检查状态：

rostopic echo -n 1 /wall_perch/status

应从 IDLE 进入：

state_name: "FRONT_WALL_DETECT"

检查正式输出：

rostopic echo -n 1 /mavros/setpoint_raw/attitude

接管第一帧等于 ALTCTL 当前目标推力；随后 1.0 秒平滑回到 0.45。


步骤 5：移动纸板触发状态机
--------------------------

建议使用两块纸板，让顶向传感器在整个过程中始终有有效回波。

1. 前向纸板距离小于 0.50 m，保持至少 0.4 s：

FRONT_WALL_DETECT -> SLOW_APPROACH

2. 前向纸板距离小于等于 0.20 m，保持至少 0.3 s：

SLOW_APPROACH -> FLIP_TO_WALL

3. 顶向纸板距离小于等于 0.05 m，保持至少 1.0 s：

WALL_CAPTURE -> WALL_HOLD


终端 7：查看电机转速
--------------------

cd /home/art/桌面/catkin_ws
source devel/setup.bash

rostopic list | rg '/mavros/esc_(status|telemetry)'

如果存在 ESC 状态：

rostopic echo /mavros/esc_status

如果存在 ESC 遥测：

rostopic echo /mavros/esc_telemetry

如果两个话题都没有实时数据，使用 QGroundControl 查看 PX4 ULog 中的 ESC RPM。


结束测试
--------

1. 发送取消侧吸：

rostopic pub -1 /attachment/terminal_command std_msgs/String "data: 'cancel'"

2. 立即解除锁定：

rosservice call /mavros/cmd/arming "value: false"

3. 切回定高模式：

rosservice call /mavros/set_mode "{base_mode: 0, custom_mode: 'ALTCTL'}"

4. 确认：

rostopic echo -n 1 /mavros/state

必须显示：

armed: False

5. 确认解除锁定后断开电调电源。
6. 在侧吸链路终端和 MAVROS 终端按 Ctrl+C。


常见问题
--------

一、FCU 或雷达报 Permission denied

不要使用 sudo roslaunch。用以下格式启动需要串口的进程：

sg dialout -c "bash -lc '需要执行的 roslaunch 命令'"

也可以注销 Ubuntu 并重新登录，使新会话自动获得 dialout 组。


二、状态一直是 IDLE

依次检查：

rostopic echo -n 1 /sensor/health
rostopic echo -n 1 /mavros/state
rostopic echo -n 1 /operator/command
rostopic echo -n 1 /attachment/flight_phase
rostopic hz /mavros/setpoint_raw/attitude

需要同时满足：

ceiling_valid: True
front_valid: True
armed: True
mode: "OFFBOARD"
operator mode: 3
operator enable_control: True


三、发送 wall 后没有 PRESTREAM

检查是否误启动 lidar_dual.launch：

rosnode list

如果只有雷达、sensor_range_manager_node 和 operator_gate_node，说明启动入口错误。
停止 lidar_dual.launch，然后启动 wall_motor_bench.launch。


四、PRESTREAM 后不能进入 OFFBOARD

先确认设定值约为 50 Hz：

rostopic hz /mavros/setpoint_raw/attitude

观察阶段：

rostopic echo /attachment/flight_phase

只有阶段到达 ENTERING 后，才可手动调用：

rosservice call /mavros/set_mode "{base_mode: 0, custom_mode: 'OFFBOARD'}"
