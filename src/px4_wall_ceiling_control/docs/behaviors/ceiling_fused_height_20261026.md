# 顶吸使用 PX4 融合高度与速度（2026-10-26）

基线：test1019 的 6467ded。用户明确选择 `/mavros/local_position/odom` 的 PX4 融合本地高度和速度作为主反馈，测距用于有效性检查，气压只作辅助对照。

## 当前反馈与流程

- 当前控制台启动入口启用 `detach_fused_height_enabled=true`、`motion_control_enabled=true`、`ceiling_height_handover_enabled=true`，关闭直接气压高度控制。原气压模式仅为显式旧配置兼容，融合模式运行中不会自动回退。
- 高度使用已知 ENU 本地坐标系下的融合 `position.z`，竖直速度沿用融合速度及现有坐标变换。要求里程计接收/源时间新鲜、完整数据有限、竖直位置估计标志有效；沿用光流质量、积分时间、源时间和 `OpticalFlowRad.distance` 有限且正值等检查。原始距离不直接当作本地高度，也不与气压做额外加权平均。
- 在进入 HOLD 时冻结本轮融合高度参考，脱离下降量为参考高度减当前融合高度。未进入 HOLD 的现有异常脱离路径单独捕获有效参考；正常下降/恢复中不重新锚定。
- 下降达到至少0.50 m后进入恢复，保留原0.45～0.55 m高度带、速度/姿态/漂移、遥控协调及连续新反馈稳定条件。恢复稳定后锁定实测姿态、继续高度闭环，等待晚于锁定时刻的第三次有效 CH12，再请求 POSCTL，最终以实际模式反馈确认交回。
- 融合高度、竖直位置估计或测距/光流反馈无效时禁止据此确认下降、恢复或交回，不用气压替代。单次竖直位置变化超过 `odom_vertical_jump_m=0.25 m + |vz|×dt` 时锁存故障，防止将估计跳变当作脱离下降。该保护值是当前初值，未做实飞调参。
- 气压参考与换算下降量仍独立记录和显示。气压单独变化不能使融合下降达标；气压缺失或与融合高度不一致，不作为正常融合恢复的硬门槛。

新增状态字段：`height_feedback_valid`、`height_reference_ready`、`fused_height_m`、`hold_fused_height_m`、`fused_vertical_speed_mps`、`baro_descended_height_m`。测试台显示融合高度/竖直速度、融合下降量与独立气压对照，两个测试面板的等宽结构保留。
