# test1019 水平恢复A版（2026-10-23）

只调整脱离/恢复阶段的接入时序，不增加制动力、增益或姿态边界，不修改飞控参数。

## 行为

- 新鲜odom的倾角回稳确认与合法光流/估计器反馈的连续确认并行。
- 等待合法的新样本可保留独立姿态确认；过期、无效光流/估计器、融合epoch变化、姿态硬越界仍清理资格。原来的恢复后新估计器/完整光流围栏保留。
- 只有已经完成接入、同一反馈周期持续有效的短暂软暂停，可使用快速重接入。重新接入仍从最后实际发送的姿态开始，并受最终输出倾角/斜率限制。
- 输出权限或有效输出丢失、真实反馈失效、新动作会清理快速接入资格。没有已经完成的接入历史，或暂停过长，仍走完整接入。
- 暂停和接入期间不积累积分/补偿时间；重复tick不能推进进度，单tick仍最多计算50ms。

## 参数

- `recovery_horizontal_reentry_blend_s: 0.30`：首次/硬恢复路径，保持。
- `recovery_horizontal_soft_reentry_blend_s: 0.15`：新增，仅合格软恢复。
- `recovery_horizontal_soft_pause_max_s: 0.75`：新增，超过此时间不享有快速路径。
- 加速度修正上限0.30m/s²、Kp/Ki、5°总倾角、5/8/10°保护、30—45°/s缩权、融合缓冲和确认时长均保持。

`horizontal_velocity_reason` 追加倾角/角速度/接入权重及“软恢复/完整接入”的进度，沿用原消息接口，日志器无需修改消息定义。

## 验证边界

新增 `test_recovery_a_response.py`；原保护测试保留，只更新明确改变的软恢复接入速度断言。固定记录回放验证接入与权重变化，不代表真实飞机闭环效果。需要受控验证与PX4 ULog后才能确认实际减速效果。
