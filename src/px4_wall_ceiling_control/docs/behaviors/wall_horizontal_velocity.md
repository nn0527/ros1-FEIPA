# 侧吸水平速度控制（2026-10-15）

`wall_console_flight.launch` 启用光流辅助的水平速度环，遥控入口和正常恢复出口为 POSCTL。吸顶保持原 ALTCTL 流程。默认配置和其他启动文件仍关闭此功能。

## 数据来源

速度取 `/mavros/local_position/odom` 中 PX4 融合后的速度，按 `child_frame_id` 的机体速度旋转到 ENU，只转换一次。接近方向沿本次接管保存的航向，不随偏航修正改变墙面方向。不是把原始光流积分值直接当作 m/s。

使用 `/mavros/estimator_status` 的姿态、水平速度有效标志，拒绝恒位置推算模式；同时检查 `/mavros/px4flow/raw/optical_flow_rad` 的新鲜度、质量、积分时间、有限数值和正距离。此组合不等于证明 EKF 此刻正在融合光流，实际融合状态仍需 PX4 ULog 估计器状态核实。主控制台通过独立参数管理节点，在首次 WALL_HOLD 后暂停 PX4 光流和对地测距融合，离墙向水平回正且实测总倾角≤80°时请求恢复本轮原值；详见[融合参数切换](wall_sensor_fusion.md)。参数确认不代表实际融合。

## 阶段

- 接管仍须有效前距≤0.50 m持续0.40秒、两路雷达有效和原飞行/急停检查。新增新鲜有效水平速度条件。
- OFFBOARD 确认后 SLOW_APPROACH：前向目标0.05 m/s、横向0。目标速度变化上限0.10 m/s²，速度误差增益1.5 s⁻¹，水平加速度需求矢量上限0.30 m/s²。以悬停附近的重力加速度关系换算推力轴方向。最终仍经总倾角5°、推力轴变化10°/s、航向变化20°/s限制。固定前倾3°和固定右倾1.7°不参与本模式，遥控修正仍经过最终限制。
- 雷达失效：目标前进速度退回0，用有效水平反馈制动；光流/水平估计失效：取消自主水平倾角，保持原水平姿态目标、报告等待，不能声称保持住实际位置。原20秒接近总时限包含等待。重新有效后继续；翻转确认重新计时。
- 一帧新鲜有效的原始前距≤0.20 m（flip_trigger_hold_s=0，不等待滤波或连续确认）：沿原 FLIP_TO_WALL、WALL_CAPTURE、WALL_HOLD、DETACH_ROTATE 主体轨迹运行，树莓派水平环清除历史并暂停；首次进入 WALL_HOLD 时异步关闭光流与对地测距融合参数，原始采样及独立雷达继续运行。
- 回正末段：先等待两项融合参数恢复原值并完成1.2秒应用缓冲；原轨迹目标倾角≤5°、实际倾角≤10°、角速度≤45°/s后，等待满足所有门槛后的新光流、估计器及里程计样本；连续有效≥0.30秒且至少2个新光流样本后恢复水平环，目标水平速度0。不会用墙面阶段缓存的数据立即刹车。
- RECOVER/ABORT：原高度、竖直速度、距离清除等条件继续适用；另要求水平速度≤0.10 m/s、实际总倾角≤5°、角速度矢量幅值≤10°/s，至少3个新里程计样本并持续1秒。EXIT 至实际 POSCTL 确认仍连续水平制动，保持输出所有权。服务返回成功不等于飞控已完成模式切换。

新参数为首次验证起点。加速度需求上限和姿态上限约束控制目标；电机推力、质量、延迟、外扰会使实际速度、加速度或倾角超出目标，不能解释为硬保证。原接近推力配置保留；恢复高度环和最终总推力上限继续使用原设定。

## 记录

WallPerchStatus 增加水平环开关、就绪/生效/稳定状态、等待原因、ENU 实测/目标速度、水平加速度需求及光流质量。CSV 保存这些字段，ROS bag 增加原始光流。网页展示闭环状态、水平速度大小和光流质量。独立 WallSensorFusionStatus 话题及 wall_sensor_fusion_* CSV 字段记录参数事务，网页“参数切换”详情显示原值、请求值、确认值及时间；它们不证明实际融合。

## 加载

须在 `ros1_noetic` 内 catkin_make，并重启整条基础程序以加载新的消息定义和源代码。只在新鲜飞控状态确认未解锁时重载；不发送解锁、OFFBOARD、起飞或机动请求进行验证。

## 2026-10-22：回正与水平纠偏连续协作

恢复阶段的回平目标与速度修正共用本次冻结的接管航向；光流准入变化不再切换到另一套 `q_hover` 航向。
大角度 DETACH_ROTATE 原轨迹不改，只有末段原有目标/实测倾角门通过后才允许速度修正。

初次准入、真实反馈失效后的重新准入仍要求角速度≤45°/s、新鲜传感器样本和原连续确认时间。
已经准入且反馈持续可靠时，角速度30–45°/s将修正权重线性降至零并暂停积分；≥45°/s只回平，
保留健康反馈轮次而不反复重建。此时 `horizontal_velocity_ready` 可为真、`horizontal_velocity_active` 为假，
不代表在高角速度下继续按旧速度纠偏，也不代表已经满足稳定交回条件。
非有限角速度、大倾角、失效/过期光流、估计器或融合数据仍执行原失效保护。
失权仍由实际输出权限和最终 mux 拦截，保留 ready 不能授予权限。

恢复修正从已验证的新鲜实际输出推力轴平滑接入，默认 `recovery_horizontal_reentry_blend_s=0.30`。
无法验证实际输出时以回平轴为候选混合起点，不把缓存输出当作速度反馈；最终 mux 仍独立限速。
混合和降权期间冻结积分、丢弃累计积分时间；停顿单次只消费≤50 ms，不追补。
反馈真正失效时清除控制历史、停止旧速度修正并保持回正；恢复后重新确认并混合接入。

ABORT 下实测与上一条实际输出都在5°锥内的普通修正同样受推力轴10°/s、航向20°/s限制。
实测大倾角、姿态未知、上一输出大倾角或没有有效输出历史时，保留紧急回平通路；
有有效历史时航向仍单独限速，避免把偏航突变当作回平动作。急停和失权检查不变。
诊断 `abort_level_immediate` / `abort_near_level_slew` 区分这两种输出行为。

## 2026-10-22：提前回正优先

仅恢复阶段在原10°硬门槛之前新增实测总倾角降权：≤5°不因倾角降权，5–8°线性减小水平修正，
≥8°修正为零、只回平。健康反馈轮次仍保留；姿态回平使用同一冻结航向。
倾角权重与既有角速度权重取较小者，所有降权期间冻结恢复积分并丢弃累计积分预算。
普通接近控制、大角度离墙原轨迹、竖直增益、PX4参数、推力限幅/限速、失权与急停保护不改。

达到8°后锁存“先回平”：回到7°不会立刻重新纠偏；须实测倾角≤5°、角速度矢量幅值≤原软门槛30°/s，
以至少两个不同源时间的新鲜姿态样本，在源时间和实际经过时间上均连续满足0.30秒。
超门、倒时或样本间断重新确认；重复样本与排队补发不能推进确认。之后沿用0.30秒实际输出平滑重入。
>10°原硬保护仍清控制历史；该清除及真实反馈失效不会擦除待完成的回平锁存。
新动作/释放显式清除此锁存，避免继承上一轮动作；保留ready不能绕过输出权限。

新增启动参数：`recovery_horizontal_tilt_soft_deg=5.0`、`recovery_horizontal_tilt_stop_deg=8.0`、
`recovery_horizontal_level_hold_s=0.30`；要求0<soft<stop<原硬倾角门，确认时间正且≤2秒。
这组数值是受控验证候选，不保证实际姿态永远小于8°或高度振荡消失。
水平状态原因区分“姿态回正优先/等待连续回稳”和“角速度受限”，显示各自权重及最终混合权重。
