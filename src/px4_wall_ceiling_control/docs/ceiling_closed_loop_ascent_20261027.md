# 控制台顶吸：从任意有效距离闭环接近与接触确认

本配置在 wall_console_flight.launch 中开启 closed_loop_approach_enabled；普通/旧台架入口默认仍关闭。必须已在POSCTL稳定飞行、已解锁且急停清除，并满足失联保护核验、平衡姿态/推力、估计器、里程计、光流/底部距离有效等原有条件。取消的是1m距离限制，不是传感器有效性和安全准入。

## 正常流程

PRESTREAM → ENTERING → OFFBOARD实反馈 → CEILING_ARMED → APPROACH → ATTACH_CONTROL → SURFACE_HOLD → CH12脱离 → DETACH → RECOVERY_HOVER → 稳定锁姿态 → 第三次CH12 → 实际POSCTL确认。

- 顶部有效测距在量程内即可准入，activation_distance_m不再约束此分支。
- APPPROACH使用原始与滤波顶距较小值，按当前姿态投影为竖直距离；上升速度目标为最大速度、距离比例目标、制动速度界限三者最小值。当前最大0.15m/s、距离增益0.5/s、目标加速度0.15m/s²。竖直速度误差经现有推力闭环作用，水平姿态控制保持现有捕获参考点及限幅。
- 顶部测距用于闭环接近，底部光流距离继续参与现有质量/有效性检查；高度与速度使用PX4融合里程计，不另外将上下距离直接相加或创建未经标定的高度融合。
- 当前有效原始顶距≤0.067m、|竖直速度|≤0.10m/s、实际倾角≤5°，且运动反馈有效、未暂停时，进入ATTACH_CONTROL。先前一帧近距离而最新帧已远离，不能启动接触控制。
- ATTACH_CONTROL不保留主动上升速度目标。继承本轮新鲜输出推力（否则继承上一控制候选/捕获支撑），限制在既有接触推力边界内，按0.02归一化推力/秒调整；上限0.55。距离接近0.050m目标后逐步衔接0.50保持推力。
- 至少经过0.5s接触控制，原始及滤波距离均在0.050±0.010m、原始距离≤0.067m、|vz|≤0.10m/s、水平速度≤0.15m/s、倾角≤5°、总角速度≤20°/s、推力与0.50差≤0.005，且反馈有效，连续新测距与新里程计样本覆盖0.5s，才HOLD。定时器重复同一帧不能确认。5s未稳定进入原有故障处理；当前abort_land_on_fault=true，进入ABORT自动降落意图分支。

## 时间、行程与失效保护

- 从CEILING_ARMED捕获初始顶距与融合高度，任务预算=max(原12s, 初始竖直顶距/(0.5×最大上升速度)+接触超时5s+裕量5s)，最多300s。此总时间不随顶距丢失而冻结。
- 相对初始高度上升行程最多min(初始竖直顶距+0.30m,40m)，超过即ABORT；40m是软件上限，并非光流实际有效量程保证。
- 顶距无效立刻将期望上升速度降为0，实际目标按原加速度限制平滑制动；持续不可用2s即ABORT。传感器本身还有0.60s新鲜度判定。
- 接触阶段顶距丢失不得继续增加压力或确认HOLD。磁异常、估计器/飞控/里程计故障、急停及运动限制沿用原保护。
- HOLD仍为推力0.50、超过5s未脱离即ABORT；正常脱离仍按融合高度下降0.50m，恢复稳定并第三次CH12确认交回。
- 实体机构输出和ACK仍采用当前配置（关闭），软件阶段不能证明实体吸附/释放成功。

## 新参数

| 参数 | 默认 | 含义 |
|---|---:|---|
| closed_loop_approach_enabled | YAML false，控制台launch true | 开启新控制台流程 |
| approach_distance_kp | 0.50 | 顶距误差→上升速度增益，1/s |
| approach_max_duration_s | 300 | 总任务时间硬上限，s |
| approach_max_ascent_m | 40 | 相对起点上升行程硬上限，m |
| approach_range_loss_timeout_s | 2.0 | 顶距判无效后允许等待时间，s |

单元回归及Docker编译不代替接触距离标定、受约束台架与真实飞行验证。程序部署后须重新启动顶吸基础链路才会加载；本次没有启动控制链路或执行试飞。
