# 离墙 demo v1：从指令到水平稳定

适用入口：`detach_range_height_enabled=true` 且不是测距台架模式。控制台飞行入口启用此路径。无需增加模式开关。非测距兼容路径保留。

## 一条姿态轨迹、两个推力阶段、一个独立完成事件

1. **离墙请求**：姿态新鲜、姿态估计有效、OFFBOARD/解锁/权限有效、存在新鲜且归本节点所有的最终姿态及推力输出，即开始。去掉离墙前0.5秒稳定窗口、15度轴偏差、25度/秒准入限制和光流平衡基准的准入依赖。全局异常角速度、急停和控制权限检查继续有效。离墙请求后及回平期间，顶部/前部测距不作为安全准入条件。
2. **回平**：从最后实际发送的姿态开始，按 `detach_time_s=3.0` 的五次平滑曲线插值到本次水平姿态。新鲜实测机体倾角≤30度后接入动态制动，使用实测姿态及角速度调整后段目标，继承最终已发布姿态和导数；3秒是名义轨迹时长，制动规划未完成时不会按墙钟强制结束。第一段与制动段均保留跟踪误差保护，目标相对实测领先超过30度时暂停轨迹推进，等待机体跟上后按受限单步继续，定时步长仍至多0.05秒，实际运行超过 `detach_duration_timeout_s=10.0` 未回稳仍报错。回平整个阶段不接入水平速度姿态修正；测距下降速度仅参与推力阻尼及诊断，不因单帧越过0.8米/秒而中断姿态轨迹。水平稳定后的恢复阶段仍保留原下降速度检查。
3. **测距锁定前推力**：继承悬停支撑基准与离墙初始压墙推力，按实测姿态竖直投影提供支撑。没有高度目标。局部Z和融合竖直速度不参与。
4. **测距锁定后推力**：首个采样倾角≤10度且满足量程/时间有效性的测距，按采样姿态投影后锁定目标。目标不随测量移动。使用直接PD：`修正 = clamp(0.15*(目标-测距高度) - 0.10*测距速度, -0.12, +0.12)`，然后叠加悬停支撑基准、补偿实测姿态投影并执行推力限幅/变化率约束。速度取快速测距差分，不用慢窗口回归速度代替控制阻尼；暂时无速度时只保留高度P项，没有速度准入倒计时、积分、速度目标级联或重复接入权重。
5. **RECOVER 准入**：以动态规划完成作为轨迹完成证据，再按 `recover_positive_demo.md` 的有符号俯仰分支判定：实测总倾角<10°且pitch非负时保存实测姿态并进入RECOVER（制动最终俯仰目标仍为0°～5°）；pitch<0°进入自动降落分支；总倾角≥10°等待。此处不恢复旧的0.3秒姿态稳定等待，制动自身持续使用实测角速度。RECOVER不再自动后退；姿态稳定后交回POSCTL，见 `recover_positive_demo.md` 的2026-10-25更新。

“水平稳定”指姿态回平、角速度收敛，不等于高度稳定或水平平移速度为零。后续RECOVER保持支撑与零速修正，按姿态连续稳定条件申请POSCTL；有效遥控、估计器、融合恢复及实际模式确认仍是独立交接条件。

## 留下的测距边界

- 原始量程0.02～6米，非有限数、重复/倒序/过期时间及明显高度跳点不采用。
- 首次10度；锁定后60度仅作为地面投影的几何保护，替代原15度工作门。60度不是传感器精度验证结论，尚需实测确认。
- 优先对源时间前后姿态插值；等待0.2秒仍没有配齐时，允许使用时间差≤0.1秒的最近源时间姿态。不能用任意当前姿态代替。
- 单帧无效不清除仍新鲜的速度。较快测距发布会累计至少0.05秒间隔后差分，不再因每帧间隔太小而反复丢速度。
- 高度最后有效帧超过0.6秒才失效，此后取消误差驱动、使用短时支撑；额外连续失效2秒才报故障。原目标保留，恢复后继续；不回退局部Z。
- 自动测距控制取消15秒收敛倒计时、0.3秒输出同步倒计时、6秒交接等待倒计时。显式手动改高动作仍保留15秒预算，避免重复点击无限续期。
- 推力总上限0.85、推力修正±0.12、推力变化率0.5/秒。最终输出mux仍执行实际发布姿态角速度和推力变化率限制。

`detach_brake_*` 同时作用于测距和非测距正常离墙，制动段沿用 `detach_max_tracking_error_deg` 保护；`detach_stable_hold_s` 不作为测距离墙准入等待。`detach_range_control_blend_s`、`detach_range_output_sync_timeout_s`、`detach_range_handover_wait_s` 保留配置兼容，自动demo不再使用它们中断流程。`detach_range_control_timeout_s`仅显式手动改高动作仍使用。

## 下一次如何定位问题

`/wall_perch/departure_trace` 为String JSON，版本 `departure_demo_v1`，常规10Hz，阶段或控制模式改变即时记录。自动飞行logger会录入bag和`signals.csv`的`departure_trace_json`列。

- 阶段：REQUEST_WAIT → ROTATE → WAIT_LEVEL → LEVEL_STABLE；异常单独FAULT。
- 推力模式：SUPPORT、WAIT_OUTPUT、RANGE_P、RANGE_PD、RANGE_LOSS_SUPPORT。
- 记录离墙请求、轨迹开始、水平稳定三个时间；轨迹进度及规划时长。
- 姿态采用的odom源时间、实测倾角及三轴角速度、竖直投影；候选姿态四元数/倾角/推力；最近实际发送姿态四元数/倾角/推力及发送源时间、有效且归本节点所有的标志。
- 测距原始值、投影值、滤波高度、目标、采样倾角、姿态时间匹配误差；控制用速度和有效性；P项、D项、基准推力及来源、最终修正、请求推力和限幅/限速状态。

候选输出与最近发送输出不是同一时刻的数据，诊断时按各自时间戳对齐。局部Z不进入此记录的控制输入。

代码、Docker编译和模拟输入测试只能确认实现，不能证明真实飞行一定收敛。修改未自动重启飞行节点，也未发送飞行指令。
