# test1017：脱离后的 ABORT 入口与保高回平

基线：ai_correction2 / 973d81636312e563a81acd18e304996d7208b1b0。

仅改变侧吸 DETACH_ROTATE 的结束路径。正常完成旋转后进入 ABORT；
脱离失败或取消时，只有新鲜实测 Euler 俯仰绝对值 ≤20° 才进入 ABORT。
大于20°或姿态尚不可用时先进入带 detach_abort_recovery 标记的 RECOVER。
其他阶段进入 ABORT 的逻辑，以及 ABORT 内部的姿态、推力及交接控制保留。

专用 RECOVER 从当前有效姿态建立回平目标，从最后真实发布目标连续衔接，
推力轴变化不超过10°/s，航向不超过20°/s，推力保持原0.50/s变化率与上限。
此阶段不运行水平退墙/制动闭环，也不申请自动交回POSCTL。
当前可信高度只捕获一次，并统一写入控制器、脱离及恢复三个高度参考；
保留本次垂直支撑基准和实际输出，清零积分。高度存在跳变时不直接采信，
沿用故障恢复的不同源一致样本检查，通过后重建基准。

俯仰首次满足20°门槛即可进入ABORT，无新增确认时长。门槛是实际俯仰，
不是总倾角或已稳定判据。进入后不因俯仰再次越界反复回RECOVER。
原8秒脱离时限仍有效，会触发上述恢复路径。专用RECOVER超出原恢复时限
会持续报错但不绕过俯仰门槛；不重置参考或时间，也不自动宣布成功。
急停、过期/无效必要反馈、输出权限互锁继续生效。飞控确认退出OFFBOARD
或上锁后退休本次专用恢复，不能在下一次动作复用。

达到原旋转完成条件时使用detach_rotation_succeeded标记，但不提前宣称
完整离墙验收完成。既有请求恢复/交接条件保留：总倾角≤5°，高度误差<0.20m，
水平速度<0.40m/s，竖直速度绝对值<0.30m/s，持续0.20s并有不同源样本。
按此前用户要求，旋转完成的三轴角速度模长门槛配置由10°/s改为20°/s。

WallPerchStatus和AttachmentControlCandidate追加字段，部署后所有使用这些
消息的ROS进程需要重新加载。控制台共享ROS进程也需更新消息定义。

软件测试验证状态路由、有效输出、保高参考与互锁。实际保持高度与俯仰跟随
仍受推力余量、估计器和外部作用影响；此改动不构成实机验收。
