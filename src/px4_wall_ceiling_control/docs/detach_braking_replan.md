# 实测30度后的连续减速插值（2026-10-24修正）

log64（19:35，20261023T113423Z_6591b7）中，已发目标约29.5度时，
实机仍约53.7度，回平转速约53.7度/秒。原轨迹继续向水平推进，机体高速越过水平。
本次只修改树莓派正常脱离的后段姿态参考规划；PX4角速度积分仍是独立的限制。

## 行为

`detach_brake_enabled`在wall_perch.yaml中启用，代码默认关闭以兼容未配置的旧启动方式。
普通脱离中，新鲜实测机体轴倾角首次小于等于30度时接入并锁存。
30度是实测机体轴相对水平的倾角，与原30度目标跟踪误差上限含义不同。
专用bench_wait_for_ranges模式继续使用原流程。

接入拍精确继承最新WALL发布姿态。用至少两条严格递增、有效且新鲜的发布源时间戳
估计目标角速度，三条估计加速度。导数受最终发布速度上限约束；在硬限速边界，
向限速外侧的后向差分加速度设为零，因为限速后的输出不能继续向外加速。

回平坐标使用相对悬停姿态的四元数旋转轴和带符号twist投影，避免90度欧拉角奇异。
角速度按配置转换为机体系，再计算该坐标的导数。q与-q等价。

每拍用剩余角度、实测回平角速度和停止角估计计算允许速度：

`v_allowed = sqrt((a*delay)^2 + 2*a*max(remaining-margin,0)) - a*delay`

delay包括配置的基础延迟、重规划间隔、当前插值剩余时间及目标反向所需的速度/加速度时间。
角度目标由允许速度与实测速度的差确定，并把新落点相对实测的领先/反向误差限制在10度内。
过渡过程仍可能有超过10度的既有误差；10度不是瞬时硬裁剪。

新落点可比上一目标更靠近实际机体，形成收回领先甚至反向制动需求。
每次五次插值继承上一条曲线当前的位置、速度、加速度，终点速度/加速度为零。
采用Bernstein凸包递归验证整段角度、速度和加速度范围，未证明可行的曲线不采用。
若接入时仍有外向加速度导致无法直接接上制动曲线，先用不超过0.05秒的连续过渡将
目标加速度收至零，再重新规划；两段都须通过完整限幅检查，不直接把加速度跳变清零。
重规划最小间隔0.10秒，运动段落点变化阈值0.25度；段结束后允许更小修正，
避免停在5度锥外。目标为零且整段结束才报告轨迹完成；完成后若实测高速，仍可重新制动。

反馈过期、倒序源时间或原跟踪误差门阻止进一步恶化时暂停推进，不补偿丢失时间。
暂停时优先服从反馈/跟踪保护，不能保证停顿处仍有名义C2连续性。
新落点暂时不可行时保留上一条已验证曲线并输出诊断；首次曲线不可行则按原ABORT流程退出。

高速回平期间禁止水平速度控制覆盖制动姿态；曲线完成且实际姿态/角速度满足原确认门后恢复。
RECOVER仍要求高度反馈、轨迹完成、实测倾角<=5度、总角速度<=10度/秒、
新鲜多拍持续0.30秒及已发布目标在锥内。原绝对脱离超时、下降/角速度保护、权限/急停与ABORT回平继续生效。
