# 贴墙打滑后的人工回正与手动脱离

2026-10-20：操作者要求贴墙打滑后继续保持压墙推力，用轮子调正，再手动点击脱离。

`config/wall_perch.yaml` 启用 `manual_wall_recovery_enabled: true`；节点缺省为 false，便于明确选择旧流程。

## 行为

1. 2026-10-21 更新保持入口：翻转轨迹完成且新鲜里程计的实测俯仰角 ≥80°，完全不依赖顶部测距。完成时不足 80° 进入 CAPTURE 最多等待 8 秒；FLIP 墙钟限时 6 秒。尚未满足该入口的接近、翻转或捕获等待仍保留下降/转速保护和超时。
2. 完成轨迹并满足俯仰角的同一周期允许按人工回正策略检查安全条件，避免先被单条下降越限样本抢先送进 ABORT。
3. WALL_HOLD 中下降速度、机体转速、偏离贴墙方向和顶部距离偏大只提示异常，不因此进入 ABORT 或发出水平姿态目标。告警不改写原始测距、里程计或估计器有效状态。
4. 保留原有有上限的压墙推力调节与输出速率限制，沿用压力目标姿态；绕机体推力轴的轮子转动仍按现有姿态跟随逻辑处理。这里保持的是压墙控制策略，不是锁死每个电机，也不是将飞控姿态控制完全关闭。
5. 保持状态不自动按定时器脱离。由操作者停轮、调正并手动点击脱离；提前点击则按既有请求机制等待。原有请求 8 秒超时仍生效，超时后可重新点击。
6. 脱离仍要求轴偏差 ≤15°、各轴角速度 ≤25°/s，连续稳定至少 0.5 秒，并满足原有反馈与最终输出条件。从实际发布的姿态/推力启动原有脱离、回平、退墙和交回流程。

急停、退出墙面模式、飞控状态失效、里程计过期等处理保留。人工回正模式还明确检查位置、速度、角速度和四元数均为有限有效数值。正常脱离/恢复阶段的原有安全检查不被此模式绕过。

## 边界

翻转轨迹完成及实测俯仰角达标是控制阶段入口，并不独立证明机械吸附或轮子压墙成功。顶部测距不再参与入口判断，但保留接触诊断和压力反馈。在人工回正保持阶段，即使顶部距离持续偏大，也会继续给出有上限的压墙控制，等待操作者处理。

`pin_enabled` 在当前配置保持 false；此功能针对 WALL_HOLD 中的轮子操作，不替代独立 WALL_PIN 流程。
