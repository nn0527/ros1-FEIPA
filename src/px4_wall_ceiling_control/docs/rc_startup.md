# AT9S Pro 遥控启动绑定

日期：2026-10-26（北京时间）

树莓派：192.168.2.20；页面端口：8790；ROS 容器：ros1_noetic。

## 操作

1. 保持飞控未解锁，CH6 解锁开关置低、CH7 急停未触发。
2. 油门保持最低，将左右方向及右杆上下方向回中一次。
3. 左杆右下、右杆左下，同时保持约 2 秒。
4. 识别并接受启动后短响一声；全部基础程序就绪后短响两声；启动失败长响一声。
5. 再次触发前需恢复左右方向及右杆上下方向中位；左杆油门不需要回中。

停止：飞控未解锁且飞控/遥控反馈有效时，CH12 拨一下并松开，停止基础链路；核验成功后短响三声。使用与原吸附／脱离功能相同的 MomentarySwitch 脉冲消抖逻辑，不要求保持拨杆，也不以按下次数奇偶切换启停。每次有效脉冲只停止一次。

飞控已解锁时，CH12 停止功能完全禁止，继续由原程序处理吸附／脱离。开机、失联恢复、从已解锁变为未解锁时，若 CH12 正停留在触发电平，不会补发停止；需先恢复开关静止电平再重新拨一下。停止完成后保留遥控通信，可立即重新按启动组合操作。

提示音通过 /mavros/play_tune 请求飞控蜂鸣器播放；本次现场已确认接收及成功两组提示音均可听见。

## 通道及隔离条件

实测组合条件：CH1 < 1200、CH2 > 1800、CH3 < 1200、CH4 > 1800。

启动只在飞控连接有效、未解锁、遥控数据有效、解锁开关低位、急停未触发，以及普通手动飞行模式下有效。开机或失联恢复后，如果摇杆已处在组合位置，必须先退出组合并恢复中位，不能自动重放。

飞控实测配置：摇杆解锁 MAN_ARM_GESTURE=0，解锁开关 CH6，急停 CH7，飞行模式 CH5，辅助通道 CH8、CH10。程序在连接后定期核对配置，并在实际执行启动前再次核对；关键配置变化或读取失败时禁止遥控启动，不自动修改飞控参数。

CH12 继续使用现有吸附／脱离计数及脉冲逻辑。新启动功能不检查 CH12 必须为高或低，不修改 CH12 的识别算法。现有 CH12 吸附／脱离动作要求飞控已解锁；新增 CH12 停止和摇杆启动要求飞控未解锁。CH12 停止不要求启动参数审计就绪或特定飞行模式，也不要求 CH7 急停未触发；它仅接受新鲜、连接有效、明确未解锁的飞控状态及有效 CH12 遥控脉冲，并在实际停止前重新检查。

## 启动范围

开机后只自动运行 ROS master、唯一 MAVROS 和摇杆监听器。摇杆动作调用与页面相同的 RemoteRuntime.start(config)，启动雷达及完整控制程序，不发送解锁、起飞、模式切换或吸附／脱离请求。网页控制权归属保持由现有机制处理。

保存的启动配置：飞控 /dev/serial/by-path/wall-fcu，230400 波特；顶部 /dev/serial/by-path/wall-top；前向 /dev/serial/by-path/wall-front；悬停推力 0.48；离墙定高目标 1.5 m；普通实飞配置。

程序运行成功后会同步有效现场配置，供下一次遥控启动使用。

页面执行“终止程序／停止基础链路”后，控制节点、雷达和记录进程停止；ROS master、MAVROS 和遥控监听继续运行。停止核验成功后自动恢复遥控启动待命，无需打开页面或重启服务。先恢复摇杆中位且油门最低，再拨同一组合动作即可按保存配置启动完整基础链路。

若停止清理失败，监听保持禁止状态，需先解决页面报告的残留进程或串口占用。“地面恢复 MAVROS”仍会停止并重建飞控通信，恢复期间不接受遥控启动。页面取得控制权不会禁用遥控启动；页面操作与遥控启动共用同一后端锁，依次执行。

CH12 与页面停止共用同一个后端停止方法和锁，不获取页面控制权。即使启动失败、或上次停止核验失败，只要飞控和遥控反馈仍有效且未解锁，也可再次拨 CH12 请求清理。启动过程中的 CH12 停止会取消启动，并核验启动线程已经退出，防止停止后又被旧启动线程拉起业务程序。

### 错误恢复边界

- wall_flight 退出、部分业务节点残留，但 MAVROS 和遥控通信正常：可拨 CH12 停止，听到三声后重新拨启动组合；停止会清除旧启动错误、任务请求并释放雷达串口。
- MAVROS 退出或无响应：若飞控/遥控反馈过期，不能靠 CH12 传递停止请求，也不能用缓存的未解锁状态授权清理。需确认落地、未解锁、电机停止后，在页面执行停止基础链路或地面恢复 MAVROS。
- 页面停止会保留健康 MAVROS；对已失效 MAVROS 则完整停止并核验清理，随后恢复最小遥控通信。只有确认没有控制进程和串口占用时，才清理失效 /mavros 注册并重新启动通信；不会自动恢复完整业务控制。
- 雷达或飞控掉电、接线故障、串口设备缺失、其他进程占用、配置不匹配等原因仍存在时，停止再启动不能保证解决。需先排除错误原因。

以下命令用于服务排查，正常页面停止后的遥控启动无需执行：

```bash
systemctl --user restart wall_rc_startup.service
systemctl --user status wall_rc_startup.service
```

飞控/MAVROS 刚启动时需要先等待参数缓存就绪，之后监听状态才会变为 LISTENING。
