# CH8 选择吸附方式，CH12 启动与脱离

2026-10-25，树莓派 `/home/pi/ros_ws`，分支 `test1019`（顶吸与共用选择入口同步自 `test1024`）。

实测 CH8（数组索引7）上拨约999、下拨约1999；CH12（索引11）原位约999、拨动约1999，松手返回999。

1. 正常启动程序，由飞手在 POSCTL 中起飞，CH12 保持原位。
2. CH8 上拨选择顶吸，下拨选择侧吸。CH8 单独拨动不会启动动作。
3. 拨动 CH12 并松手，启动所选动作。现有管理器检查接管条件，满足后进入 OFFBOARD，执行对应接近、吸附控制及保持流程。
4. 顶吸达到 SURFACE_HOLD 或侧吸达到 WALL_HOLD 后，再拨 CH12 并松手，请求当前动作脱离。后续按原有逻辑恢复，并经安全交接返回 POSCTL。
5. 两个吸附节点均返回空闲、操作意图待命后，可以开始下一轮。

动作期间切换 CH8 只选择下一轮模式。CH12 脱离始终对应当前动作，不会因 CH8 改变而向另一套控制器发送脱离。接近、翻转、脱离、恢复期间重复拨动不会跳阶段。网页、终端和遥控器共用操作意图。

CH8 两端阈值为 <=1200 和 >=1800，需连续稳定至少0.05秒。中间位置、缺失、非法值或不稳定时拒绝新启动。CH12 每次稳定低位到稳定高位只触发一次；启动或断线重连后若一直保持高位，必须先回低位才能触发。RC 间断超过0.5秒重置判定。

启动要求飞控连接、已解锁、心跳新鲜，两个吸附节点状态新鲜且空闲、无残留控制权，所选节点里程计有效，急停有效且未触发，以及规定的飞手模式。IDLE 聚合故障可能包含尚未进入 OFFBOARD 的正常情况，因此使用明确的里程计、飞控及管理器接管检查。HOLD 故障或反馈过期时拒绝正常脱离。顶吸算法同步自 test1024；侧吸测距、姿态及恢复算法保留 test1019 原有逻辑。

`wall_console_flight.launch` 和 `attachment_terminal_flight.launch` 默认参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| rc_wall_toggle_enabled | true | 启用 CH12 触发 |
| rc_wall_channel_index | 11 | CH12 数组索引 |
| rc_mode_selector_enabled | true | 启用 CH8 选择 |
| rc_mode_channel_index | 7 | CH8 数组索引 |
| rc_mode_up_is_high | false | 实测上拨为低值，更换遥控器后可反向配置 |

通用 `attachment_system_mavros.launch` 的 CH12 触发默认关闭。`rc_mode_selector_enabled:=false` 恢复旧的 CH12 仅侧吸操作；`rc_wall_toggle_enabled:=false` 关闭遥控器动作触发。

重启控制链路才能加载修改。本功能不执行自动解锁或自动起飞。软件编译及回归验证不代表实飞动力学验证通过。
