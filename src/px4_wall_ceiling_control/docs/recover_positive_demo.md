# 离墙 demo：DETACH 最终有符号俯仰角分支

适用于 `detach_range_height_enabled=true` 且非台架模式。改变的是实际代码，尚需实飞确认。

- DETACH 从名义 3 秒五次姿态轨迹开始；新鲜实测机体倾角≤30°后接入基于实测姿态及角速度的动态制动，继承实际发布姿态及导数，完成时间可延长。不能因经过3秒而跳过制动。轨迹结束前的负角不触发降落。
- 轨迹结束后，读取新鲜实测姿态的有符号 pitch（ROS ENU/FLU 四元数转欧拉角）。动态制动的最终俯仰目标保持0°～5°；RECOVER准入单独要求实测总倾角严格小于10°且pitch非负，满足后立即进入 RECOVER，保存完整实测姿态作基准，无原来的 5°/10°每秒/0.3 秒入场条件。总倾角≥10°继续等待，原有 10 秒轨迹总超时保留。
- 最终 pitch<0° 进入 ABORT，锁存 `abort_land_requested`，模式管理器立即异步请求 `AUTO.LAND`。此分支优先于测距故障处理，不等待高度、光流、融合恢复或摇杆回中。保留急停和飞手接管优先级。
- `mode_sent` 只表示请求已发送。等待请求后的新鲜 `AUTO.LAND` 飞控反馈；失败按现有模式重试周期重试。等待时保留现有有效安全姿态/推力输出，飞控退出 OFFBOARD 后停止 ROS 输出。禁止用旧任务、过期状态、已解除武装状态发起迟到降落。降落分支解除武装后回 IDLE。

2026-10-25：从树莓派保存的 test1024 修改迁入 test1019，RECOVER / EXIT **取消自动后退**。水平速度目标立即归零；保留冻结航向、可信悬停基准、独立侧向弱阻尼、横滚限速及实际反馈有效时的零速修正。反馈不满足修正条件时继续平滑姿态基准输出，不使用旧速度驱动。

进入 RECOVER 时仍按原实现捕获有效测距高度、平滑衔接推力；支撑和测距高度控制继续工作，但不再以墙距、高度误差或水平/垂直速度收敛作为正常姿态稳定的计时条件。本轮已有故障、姿态失效、权限丢失等仍阻止正常完成。

正常恢复稳定要求：新鲜有效姿态与角速度，总倾角≤10°、总角速度≤20°/s，连续稳定≥0.50秒且至少两个不同里程计源样本。角度或角速度超限、源时间倒退或样本中断会撤销稳定资格。不再等待一帧前距>0.50m；前距变大也不会提前进入 EXIT。

稳定后进入 EXIT 并申请 POSCTL。模式管理器仍独立复核姿态、输出新鲜度、有效遥控输入、位置/速度估计及融合恢复。收到请求后的新鲜 POSCTL 飞控反馈才释放控制；模式服务返回成功本身不代表交接完成。等待期间继续受控输出；安全条件变化时撤销交接资格。

该更改仅适用于测距实飞入口的正常锁定姿态恢复分支，原回平轨迹、负俯仰自动降落、台架/非测距兼容路径保留。CH12、网页、终端继续共用操作入口。变更需重启控制链路加载，本次未自动启动实飞。

状态/日志增加：`detach_final_pitch_deg`、`recover_attitude_locked`、`recover_entry_attitude`、`recover_stable`、`abort_land_requested`。`departure_trace` 包含实际锁定姿态及以上分支标志；`detach_range_config_json` 在新 RECOVER 中显示生效的稳定余量。
