# RECOVER 慢速退墙

进入 RECOVER 时，用此时新鲜有效的测距几何高度一次性重设保高目标，不再追旋转阶段首次锁定的旧高度。若入口高度暂不可用，取得新鲜高度前不发后退目标；之后不随实际高度滚动重设目标。原推力值、限幅及变化率保持连续。

姿态基准从 RECOVER 入口实测姿态，以不超过 10°/s 平滑移向本次接管前已验证并冻结的 POSCTL 悬停平衡推力轴；没有可信平衡基准时禁止猜测并开始后退。融合恢复等待期间也继续平滑回平。水平速度修正仍限于原有 0.30 m/s²，回平后总倾角不超过 5°，航向使用入口冻结航向。

水平目标为机头反方向 0.05 m/s、横向零速；前向雷达失效不暂停或取消该动作。仅新鲜、有效、属于本轮 RECOVER 之后且严格大于 0.50 m 的一帧墙距即可锁存停止条件。回调中立即把速度目标归零，随后主动制动并进入 EXIT 接管申请流程。无需多帧确认、持续测距或额外后退半米；条件是雷达测得绝对墙距大于半米。锁存后，短帧、无效帧、雷达掉线或融合短暂失效均不重新启动后退，新动作才清锁存。

EXIT 不等于立即切模式：急停、反馈新鲜性、PX4 位置/速度估计、有效遥控、输出归属、融合参数恢复及必要的姿态/速度稳定检查仍保留。收到新鲜 POSCTL 确认后才释放 ROS 控制。没有前向有效远距帧时不能确认已离墙，也不会用计时冒充距离完成。

融合恢复卡点：本次日志显示参数操作前的同步落盘耗时约 10、11、31 秒。合并前发现现场另外一处已把融合节点改为 MemoryRestoreJournal，worker 不再传入磁盘 journal。为不覆盖并行改动，本次保留现场方案并对它进行兼容回归，不部署另一套持久化实现。参数设置 ACK、应用缓冲和新鲜读回验证仍须保留，速度控制还要求参数恢复后的新里程计、估计器与完整光流样本。重要限制：仅内存保存的原参数值不能跨进程重启或掉电恢复；不要在空中重启融合节点，重启后须在地面核对 EKF2_OF_CTRL、EKF2_RNG_CTRL，不能把当前读取值自动视为本轮修改前的原值。

本改动不修改 PX4 PID、急停阈值或遥测失效阈值。实际效果仍需地面检查与受控试飞验证；前向雷达始终无有效帧时动作不会自行判断完成，须人工接管。
