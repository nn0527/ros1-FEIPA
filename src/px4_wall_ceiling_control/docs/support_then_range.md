# 控制台测距脱离：两段垂直控制

适用范围：`detach_range_height_enabled=true` 的正常侧吸脱离（控制台默认）。
非测距兼容入口和受限台架流程保留原路径，不会因测距失效自动切入。

1. 从脱离准入起，不以局部 Z 或融合竖直速度检查竖直状态。开始脱离后没有高度目标。
   使用本次接管的悬停支撑基准、脱离开始实际压墙推力和实测姿态，执行原支撑混合、
   倾角补偿、推力上限及相对实际输出的变化率限制。无高度/速度比例修正，无积分，
   不执行旧高度连续性检测、跟随目标或重锚。姿态回平、角速度保护、权限及急停仍有效。
2. 第一条合格对地测距完成采样时刻姿态匹配后，锁定投影及安装偏移修正后的高度。
   从新鲜实际输出初始化测距控制器，随后只用测距高度和快速测距速度闭环。
   速度未建立或测距短时失效沿用受限支撑及超时故障；目标保留，禁止退回局部 Z。

锁定前 `vertical_reference_valid=false`、`vertical_control_active=false`，高度目标、
高度误差和目标竖直速度为 NaN；`recovery_support_valid` 独立表示推力支撑有效。
候选消息 `departure_support_only=true` 使输出复用器明确检查支撑阶段元数据，
并避免因无关局部 Z 无效拒绝姿态/推力输出。

没有测距就不能宣告高度稳定或正常完成。原回平超时进入 ABORT；ABORT 不表示
已经交回人工控制，权限仍在时仍仅给受限支撑，不恢复融合竖直闭环。
测距前没有可信的下降速度保护；不能用融合速度伪装成有效保护。

测距是当前照射地面的高度基准，不是海拔。改变地面或照射目标仍会改变读数。
软件回归/固定观测回放只验证指令策略，不能证明真实高度保持效果。
