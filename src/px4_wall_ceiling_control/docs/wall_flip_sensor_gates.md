# 侧吸翻转与顶部雷达接入

- 翻转触发只使用前向雷达：数据有效、新鲜，滤波前距满足现有 0.20 m / 0.30 s 条件。
- 顶部雷达无效、过期或缺失，不再清空前距连续确认计时，也不阻止侧吸接管与翻转。
- `flip_top_start_fraction: 0.90`：翻转最后 10% 才消费顶部测距。当前 `flip_time_s: 2.00`，接入起点为 1.80 s。
- 必须是接入窗口开始后采样的新帧；有时间戳时同时核对采样时间。翻转前或前 90% 的缓存帧不能触发 HOLD。
- 后段只需一帧合法、新鲜的顶部测距即可直接进入 WALL_HOLD，不要求该帧小于接触距离，也不再等待三帧中值或连续 1 s。
- 到 2 s 仍无有效帧时进入 WALL_CAPTURE 等待；后续第一帧有效数据进入 HOLD。原有 8 s 捕获超时仍会中止等待。
- 直接 FLIP_TO_WALL → WALL_HOLD 时保留该时刻的姿态目标，避免跳到完整翻转终点。
- 有效帧不等于实体接触确认。HOLD 之后原有压力控制、顶距超过 clear 阈值的中止判断，以及飞控/里程计/急停/角速度保护继续适用。

部署后需要在落地、上锁后重启相关侧吸控制节点，现有 Python 进程不会自动加载新源码或 YAML。
