# 侧吸翻转、俯仰角准入与顶部雷达诊断

- 翻转触发只使用前向雷达：数据有效、新鲜，滤波前距满足现有 0.20 m / 0.30 s 条件。
- 顶部雷达无效、过期或缺失，不再清空前距连续确认计时，也不阻止侧吸接管与翻转。
- HOLD 准入完全不使用顶部测距：没有测距、无效帧、旧帧、距离偏大均不阻止准入，也不要求一帧有效数据或连续近距 1 s。
- 必须先完成翻转轨迹（`flip_time_s: 2.00` 的累计轨迹时间），再由新鲜里程计的实测俯仰角判断；不能仅凭命令角度或经过 2 s 判断完成。受姿态跟踪限速影响，实际墙钟时间可能更晚。
- `hold_entry_min_pitch_deg: 80.0`：翻转完成且实测俯仰角 ≥80° 直接进入 WALL_HOLD；不足 80° 则进入 WALL_CAPTURE，保持既有捕获控制并等待实测俯仰角达到 80°。当前翻转方向为正俯仰，反向负俯仰不满足准入。
- `capture_timeout_s: 8.00`：从进入 CAPTURE 起最多等待 8 s；到期先中止，即使该周期俯仰角恰好达标也不再准入。
- `flip_duration_timeout_s: 6.00`：FLIP 阶段独立墙钟超时为 6 s，达到期限仍在翻转阶段则中止。
- `flip_top_start_fraction: 0.90` 和 `_late_top_frame_ready()` 保留用于顶部反馈诊断。`hold_entry_top_distance_check_enabled: false`、`top_contact_distance_m: 0.056`（≤5.6 cm）及原有判断代码均保留；即使打开旧距离开关，也只影响旧诊断，不恢复顶部 HOLD 准入依赖。
- 直接 FLIP_TO_WALL → WALL_HOLD 时保留该时刻的姿态目标，避免跳到完整翻转终点。
- 操作命令须持续有效并请求侧吸，不能有取消请求；飞控须连接、解锁且处于 OFFBOARD，飞控状态和里程计须新鲜，急停保护须放行。
- 当前 `manual_wall_recovery_enabled: true`：满足翻转完成与俯仰角准入后，进入/保持 HOLD 只检查运动反馈为有限数，不因角速度或下降速度幅值超限而拒绝，也不因顶部距离偏大自动中止；飞控、里程计和急停保护仍生效。未满足俯仰角准入时仍执行 FLIP/CAPTURE 的角速度与下降速度保护。
- 翻转完成和俯仰角达标不等于实体接触确认。原有顶部接触诊断和 HOLD 压力反馈保留。

部署后需要在落地、上锁后重启相关侧吸控制节点，现有 Python 进程不会自动加载新源码或 YAML。
