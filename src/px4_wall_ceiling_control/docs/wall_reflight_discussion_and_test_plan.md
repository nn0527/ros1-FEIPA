# 直墙侧吸复飞：理论讨论、结构参数与现有代码测试计划

日期：2026-10-01

本文记录当前讨论结论与待验证事项。仅新增文档，不修改控制程序或参数。下一步先测试现有姿态控制实现，根据日志和实物表现定位问题，再选择改动。

## 1. 测试范围与目标

当前范围：竖直平面墙，墙面法向不变；只考虑轮子/机身与墙面接触，不考虑其他障碍接触；爬壁平移后先停稳，再触发复飞。斜墙、曲面墙和运动中立即复飞后续扩展。

第一阶段区分三个结果，不能互相替代：

1. 水平恢复：机体转到接近水平，角速度收敛。
2. 接触解除：机体确实脱离墙面，而不是雷达仅因转动读数变大。
3. 稳定悬停：高度和水平速度受控；定点悬停还需要可靠定位与平移控制。

最终希望支持任意沿墙朝向下的水平恢复，但原代码仍要求回到初次贴墙姿态附近。原代码测试首先建立旧策略基线，不代表已实现新目标。

## 2. 已确认的现有实现

### 2.1 控制链路

```text
MAVROS odom / 飞控状态 / 测距 / 操作指令
    → wall_perch_decision_node
    → 姿态四元数 + 归一化总推力候选
    → attachment_output_mux_node
    → /mavros/setpoint_raw/attitude
    → PX4姿态环 → 角速度环 → 控制分配 → 电机
```

ROS没有直接控制四个电机，也没有发送角速度目标。实测角速度用于稳定与超限判断。PX4内部已有角速度闭环；新增角速度控制是让ROS直接提供其目标，绕过PX4姿态外环。

### 2.2 四种姿态的区别

| 名称 | 获得方式 | 当前用途 |
|---|---|---|
| `q_hover` | 侧吸开始时读取航向，构造横滚0、俯仰0的水平四元数 | 复飞终点；复飞触发时未重新计算 |
| `q_wall` | `q_hover`乘以配置的俯仰旋转，当前为+90° | 侧吸翻转目标 |
| `q_hold_reference` | 进入`WALL_HOLD`时记录实测姿态，取不到时回退到`q_contact` | 压墙轴维稳与复飞准入参考 |
| `q_detach_start` | 进入`DETACH_ROTATE`时记录实测姿态 | 本次复飞插值起点 |

“初次贴墙姿态”指测距确认接触后进入保持状态时记录的姿态，并非首次碰墙的物理瞬间，也不一定恰好90°。

姿态四元数不包含位置或高度。高度独立处理：复飞触发时记录当前odom高度作为保高目标。爬到新高度后复飞不会主动回到初次贴墙高度；沿墙横移后也没有回原位置或水平制动控制。

### 2.3 触发、插值与结束

默认`hold_time_s=0`，需要操作指令触发。当前准入门槛包括：

- 与初次贴墙完整姿态夹角≤10°；该门槛会限制沿墙转向。
- 与保持压墙轴、跟随当前绕轴转动的姿态夹角≤5°；该门槛仍使用初始轴方向。
- 三轴角速度各自绝对值≤0.15 rad/s，竖直速度绝对值≤0.15 m/s。
- 稳定持续至少0.5 s，至少两个odom样本；odom新鲜且满足保持进入过渡条件。
- 传感器、飞控连接、解锁和OFFBOARD等状态满足要求。

复飞起点与终点固定，每周期计算时间进度：

```text
s = clamp((当前时间 - 复飞开始时间) / detach_time_s, 0, 1)
u = 10s³ - 15s⁴ + 6s⁵
q目标 = slerp(q_detach_start, q_hover, u)
```

当前配置`detach_time_s=4 s`，发布频率50 Hz。五次函数使目标起止角速度、角加速度为零；四元数插值使目标连续。纯90°转平时，目标峰值角速度约42.2°/s。

消息带当前时间戳，但ROS不是将整条预约轨迹交给PX4。ROS逐周期发送即时目标，PX4闭环追踪最新目标；实际落后不会自动停止ROS计时。

4 s后进入`RECOVER`，继续发送水平目标。满足姿态、角速度、竖直速度、起始高度附近及顶部距离解除条件后才退出。现有恢复阶段没有总超时；终端飞行入口在完成并释放控制后请求ALTCTL。

### 2.4 推力与测距

顶部雷达按安装位置命名：水平时朝上，侧吸后朝墙。贴墙阶段用其距离调节螺旋桨压墙推力，不是测量或计算接触压强。

现有复飞接近侧立时使用名义保持推力`0.45 × 1.5 = 0.675`，随后随实测竖直推力分量逐渐切换到高度/竖直速度反馈与倾角补偿的推力，最大归一化请求为0.85。它没有独立主动减压阶段；这些归一化值不是牛顿，也不是实际RPM。

## 3. 理论判断与尚未证实的假设

### 3.1 90°姿态与下降

90°本身不是四元数姿态控制的奇异点。自由飞行中，机体可以在下降时仍维持侧立姿态，不能把下降直接等同于姿态失控。

若推力轴与世界竖直向上夹角为θ，理想竖直推力为：

```text
Fz = T cosθ
```

接近90°时竖直推力很小。墙面接触不再承重后会下降，即使姿态闭环仍正常。转平期间是否可控取决于电机差动推力余量、饱和、接触反力、摩擦和反馈质量。

“上部电机降速、下部保持”在某些接触布局下可能产生转平力矩，但不是通用固定电机方案。沿墙转向后，上下关系会改变，需按当前姿态计算旋转轴。四个电机一起减速主要减小压墙作用，不自动保证指定转动方向。

机体“蹬开”只是动作外观描述。当前方案不假设主动蹬墙或弹性储能；减压、重力、接触反力与电机差动推力共同决定动作。

### 3.2 姿态轨迹是否足够

第一阶段可以采用姿态轨迹加总推力，而不规划完整XYZ轨迹。接触阶段直接引入自由飞行位置轨迹也可能与墙面约束冲突。

但仍需监测下降、位移及接触解除。姿态水平不证明已经离墙或水平速度为零；定点悬停需要另外的速度/位置控制。

### 3.3 轨迹进度与控制接口

| 方案 | 优点 | 局限 |
|---|---|---|
| 固定时间姿态轨迹 | 名义速度明确、目标连续 | 实际落后时目标继续前进 |
| 姿态匹配加前瞻 | 限制目标领先实际的程度 | 可能停滞，延长缺乏竖直升力的时间 |
| 时间轨迹加反馈限进度 | 正常时按计划推进，落后时限制误差 | 需协调推力、停滞和下降处理 |
| 角速度加总推力 | 直接指定转轴与转速，保留PX4角速度环 | 需自行规划减速、停止和姿态模式衔接 |
| 四电机独立输出 | 自由度高 | 需接管被绕过的闭环、分配、饱和与稳定恢复 |

姿态路径匹配可使用四元数最小旋转夹角，不能直接用欧拉角差。仅取最近点会使目标等于当前状态而缺乏前进作用，因此需受限前瞻、邻域搜索、偏离路径检查和指令变化限制。

LQR反馈、前馈与路径前瞻属于不同层次。LQR加前馈不会自动管理轨迹进度；第一阶段无需引入LQR即可改善目标领先问题。

目前不认定角速度接口天然优于姿态接口。优先用现有代码测试，再依据结果决定是否调整轨迹、推力或控制接口。

## 4. 机身结构参数：侧吸、爬壁与复飞全流程的作用

本节覆盖自由飞行/慢速接近、翻转贴墙、接触捕获、贴墙保持、轮子爬壁与转向、脱离转平、水平恢复。参数不仅用于复飞，也用于解释前距触发、接触是否成立、贴墙承重和轮子运动。表中的作用是物理与设计意义，不表示当前程序已经实现相应模型或控制功能。

### 4.1 当前代码的覆盖边界

当前侧吸决策与复飞规划没有显式使用质量、惯量、轮子接触点、重心、轮径、机身尺寸或雷达外参。现有角度、时间、推力及距离参数属于目标/调参项，不构成接触几何模型。

`WALL_HOLD`通过飞控实测姿态跟随绕压墙轴的转动，并调节压墙推力；它没有通过轮速、轮子接触力或制动状态闭环控制爬壁运动。不能把现有姿态跟随等同于完整的轮式爬壁控制。

PX4底层的电机布局与控制分配配置也不能代替轮子—墙面接触模型。悬停推力受到质量、动力系统、电池等影响，但单个悬停推力数值不能描述完整机构。

### 4.2 参数清单

所有实测值先留空，不使用猜测值。长度用m，质量用kg，惯量用kg·m²，角度需注明deg或rad。建议统一记录在机体FLU坐标系中（X前、Y左、Z上），原点说明为飞控IMU或选定机体基准点；换算到重心时明确偏移。ROS侧世界坐标采用ENU，PX4内部坐标转换由接口处理。

|---|---|---|---|

### 4.4 关键物理关系及适用边界

- 自由悬停的理想总升力约为`mg`；接近/翻转时还需考虑加速度和倾角。归一化推力指令不能直接代入牛顿单位方程。
- 单个电机或接触力的力矩为`τ = r × F`，其中r必须从重心指向力作用点。只有姿态角度而没有力臂，不能判断具体机体会怎样转动。
- 在简化静态接触模型中，墙面切向摩擦力受`|Ft| ≤ μN`约束。侧立时能否承重取决于法向力、摩擦、轮子是否制动及接触分布；有轮子不代表自动能承重，自由滚动与制动保持不同。该关系不能直接代替真实轮组牵引模型。
- 无打滑时，轮子线速度约为`v = Rω`；转向还依赖轮距、轮组布局与约束。编码器轮速不一定等于机体沿墙速度。
- 雷达量到的是光束方向距离，而不是重心或轮子到墙的距离。需结合雷达位置、姿态和墙面法向换算；光束近乎平行墙面时换算不可靠，视场失去墙面时不能继续使用。
- 靠近墙面可能改变桨流与实际推力，接触也会改变系统动力学。结构尺寸、推力测试和日志共同用于解释，而不是只靠自由飞行标定推断贴墙全过程。

这些关系用于识别需要测量的量及解释现象，不是当前已运行的控制算法。待获得参数与测试依据后，再决定哪些模型值得进入控制代码。

### 4.5 第一轮优先补齐的结构资料

1. 当前载荷下总质量、重心位置。
2. 带机体系方向和电机编号的侧视/俯视尺寸图。
3. 轮轴、轮径、预期接触点到重心的位置，以及捕获、保持、爬壁、停稳、复飞各阶段轮子的驱动/制动/自由滚动状态。
4. 轮子、机身和桨盘相对墙面的几何余量。
5. 前向与顶部雷达安装位置、光束方向与无回波行为。
6. 当前电池条件下的悬停推力、可用推力范围和PX4电机配置。
7. 轮组驱动、编码器及接触/制动反馈是否具备，当前是否接入控制；墙面与轮胎材质。

惯量、摩擦、推力曲线等可逐步辨识；未测量前不要据其推导精确动作参数。结构资料用于解释测试，不意味着第一轮必须先完成完整动力学模型。

## 5. 反馈来源与可靠性边界

| 反馈 | 典型来源 | 主要影响 |
|---|---|---|
| 姿态/倾角 | PX4 EKF融合结果 | 转平轴、剩余角度、竖直推力补偿 |
| 角速度 | 陀螺仪经校准、滤波等处理 | 旋转控制、稳定及停滞判断 |
| 高度/竖直速度 | IMU与气压、GPS、测距或视觉按配置融合 | 承重恢复、下降监测；不是一定依赖GPS |
| 水平位置/速度 | IMU与GPS或其他定位源融合 | 离墙位移、水平制动；精度取决于配置和环境 |
| 距墙值 | 本项目外接雷达 | 有效照墙时直接测距，不代表已被PX4融合 |

odom是估计输出，不证明厘米级精度。起点相减可消除固定位置偏差，不能消除过程漂移或重置跳变。姿态、速度、高度跳变可能使目标、推力或阶段判断突变；需检查估计健康与一致性，低通滤波不能证明数据正确。

全程不使用反馈，不能可靠实现任意朝向恢复。ROS固定时序加PX4闭环仍然依赖反馈；直接开环电机时序的偶然成功不能证明可重复性。

## 6. 现有代码潜在问题与后续候选改进

| 已确认的实现边界 | 可能表现，待测试确认 | 候选改进 |
|---|---|---|
| 10°/5°准入与旧q_hover | 转向后拒绝脱离或附加航向旋转 | 更新准入和当前姿态对应的水平目标 |
| 固定时间推进 | 目标领先实际，接触解除时快速追赶 | 反馈限进度、受限前瞻与停滞检测 |
| 无独立减压阶段 | 压墙力阻碍旋转，或倾角补偿推力过高 | 协调减压、转平与升力恢复 |
| 脱离/恢复仍强制顶部测距有效 | 雷达转离墙后ABORT，或误判离墙 | 根据光束方向与阶段处理测距 |
| 恢复要求起始高度附近，无总超时 | 水平后仍长时间不退出 | 分离水平恢复与高度恢复，增加超时 |
| ABORT直接给q_hover | 异常时姿态目标跳变 | 按故障原因设计连续输出或接管 |
| 无接触结构模型 | 目标路径与实际轮子运动冲突 | 补充结构参数与路径可行性检查 |

没有试验依据前，不预设哪项是主因；也不把一次失败归因于PX4不能控制90°姿态。

## 7. 现有代码基线测试与定位方法

现有launch已接入自动旁路记录，操作步骤见[自动日志说明](wall_test_recording.md)。无需人工标记、机身参数填写或离线分析命令；工具只采集ROS程序与收到的信号，不改变飞行控制策略。真实ROS录制需要先在飞行机器完成短时验证。

第一轮不改控制代码。记录实际launch与参数覆盖值，避免只按YAML默认值解释结果。由于当前准入有限制，先测试初次贴墙朝向附近；其他朝向若被拒绝，应记录为当前准入行为。

需要同步记录：

- 状态、触发时刻、复飞进度、异常原因、模式切换。
- 决策姿态/推力候选，以及最终MAVROS输出，区分决策与输出限幅/辅助修改。
- 实测姿态四元数、角速度、目标—实测最小旋转夹角。
- 高度、竖直速度、水平位置/速度及估计健康信息。
- 顶部雷达原始/滤波值、有效性和样本年龄。
- PX4日志中的电机输出、控制分配饱和信息；有RPM反馈时一并记录。
- 同步视频：轮子接触、机体开始转动、实际脱墙、接近水平时刻。

定位顺序：

1. 是否接受脱离指令，还是卡在准入？
2. 目标是否开始变化，实际角速度是否响应？
3. 跟踪误差是否持续扩大，是否伴随饱和或接触阻碍？
4. 下降发生在接触解除前还是后，推力如何变化？
5. 是否因雷达转离墙面而进入ABORT？
6. 水平恢复后是否有残余旋转、水平漂移或恢复退出受阻？

比较指标包括最大跟踪误差、峰值角速度、高度损失、下降速度、饱和持续时间、恢复时间与重复成功率。评估限值应结合结构、空间和基线记录确定，本文不虚构阈值。
