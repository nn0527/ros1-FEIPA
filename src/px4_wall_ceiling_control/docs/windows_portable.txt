Windows 双击版（不需要 Codex、Python、ROS 或 QGC）

1. 将 WallConsole.exe 和“修改连接设置.cmd”复制到新电脑任意文件夹。
2. 第一次双击 WallConsole.exe，填树莓派 IP、用户名，认证方式选 password（密码）或 key（密钥），保存。
   password：启动时输入密码，不保存到磁盘。key：选择已授权的私钥（不要选 .pub）。
   首次连接核对并确认主机指纹，之后自动记住。
3. 浏览器自动打开。之后每次双击 EXE 即可；密码模式在本地服务重新启动时需输入一次密码。

改 IP/密钥：双击“修改连接设置.cmd”。
树莓派离线时页面也可打开，会显示未连接。
另一台电脑应使用同一版程序；树莓派仍需已有的 ROS 工作区和 Docker 环境。
关闭浏览器不会停止飞机程序。启动 EXE 不会解锁、起飞或自动发送动作。
多台电脑可同时观察，共用树莓派上的一个桥接服务。
操作前点“申请控制权”；只有一个控制端可以启动、贴墙、离墙。
换电脑操作：在待命／已交还 ALTCTL 时由原电脑“释放控制权”，新电脑再申请。
“暂停实时反馈”只停止本机推送，SSH 保持；恢复新反馈后才能操作。控制权不会因暂停释放。
断线保留控制权 30 秒，同一服务重连可继续；超过 30 秒需重新申请，动作中不能换控制端。
先检查实时连接，选择当前试验配置，再手动启动基础程序。
首次升级本版需树莓派通过 Git 同步代码，覆盖 EXE 后双击“重启本地页面.cmd”（本机服务会退出再启动）。

连接配置及日志：%LOCALAPPDATA%\WallConsole

当前贴墙流程：请求贴墙后保持 ALTCTL，由飞手手动接近；最多等待60秒。
手动接近期间并行预发送；预发送已连续就绪1.5秒且有效前向滤波距离≤20厘米连续0.30秒，即请求 OFFBOARD 翻转，不再从靠墙时重新等待1.5秒。
没有额外3秒延时；等待期间可点“取消等待”。翻转动作仍为2秒。
