Windows 双击版（不需要 Codex、Python、ROS 或 QGC）

1. 将 WallConsole.exe 和“修改连接设置.cmd”复制到新电脑任意文件夹。
2. 第一次双击 WallConsole.exe，填树莓派 IP、用户名，认证方式选 password（密码）或 key（密钥），保存。
   password：启动时输入密码，不保存到磁盘。key：选择已授权的私钥（不要选 .pub）。
   首次连接核对并确认主机指纹，之后自动记住。
3. 浏览器自动打开。之后每次双击 EXE 即可；密码模式在本地服务重新启动时需输入一次密码。

改 IP/密钥：双击“修改连接设置.cmd”。
树莓派离线时页面也可打开，会显示未连接。
另一台电脑应使用同一版程序；树莓派仍需已有的 ROS 工作区和 Docker 环境。
关闭浏览器不会停止飞机程序。启动 EXE 不会解锁、起飞或自动发送动作。
测试时只用一台电脑发动作；先检查实时连接，选择当前试验配置，再手动启动基础程序。

连接配置及日志：%LOCALAPPDATA%\WallConsole
