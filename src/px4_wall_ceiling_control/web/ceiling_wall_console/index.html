顶吸流程与遥控操作说明

CH8 上拨选顶吸，CH12 第一次启动、保持时第二次请求脱离，也可使用上方按钮。有效原始顶距单帧≤1.00 m满足距离准入，单帧≤6.7 cm进入保持；还须满足估计器、平衡基准和控制权检查。保持推力目标0.50，超过5秒未开始脱离则请求 AUTO.LAND，以飞控实际模式确认。

脱离先请求机构释放，以保持时的PX4融合高度为基准确认下降≥0.50 m，再在下降量0.45～0.55 m等恢复条件内稳定。高度与竖直速度采用 PX4 融合里程计，测距参与有效性检查，气压仅作辅助对照，不作为正常达标门槛。允许阶段摇杆可微调横滚/俯仰：人工修正时减弱位置回拉、暂停积分；回中后平滑恢复。恢复交回还需本轮遥控反馈有效、微调消退和位置权重恢复。恢复稳定后锁定姿态、高度闭环继续；第三次 CH12 确认后才请求交回，最终以飞控 POSCTL 及控制权释放确认完成。

侧吸流程与遥控操作说明

正常捕获恢复保持翻转结束时的实测姿态，关闭水平速度姿态修正及摇杆微调，高度推力闭环继续；不自动退墙。第三次有效 CH12 确认后，还须总倾角≤10°、角速度≤20°/s连续稳定0.50秒及管理器检查，才请求POSCTL。固定姿态不等于位置保持，仍可能漂移；急停、故障及外部模式切换按原保护处理。
